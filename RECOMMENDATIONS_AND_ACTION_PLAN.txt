3.1 إنشاء جدول process_x_glossary
----------------------------------
📁 الملف: جديد - سكريبت SQL
⏱️  الوقت المقدر: 30 دقيقة (إنشاء + اختبار)
🎯 التأثير: يفتح علاقة مباشرة بين Process و Glossary

السكريبت SQL:
```sql
-- Main relationship table
CREATE TABLE `process_x_glossary` (
  `id` int(11) NOT NULL AUTO_INCREMENT,
  `processid` int(11) DEFAULT NULL,
  `glossaryid` int(11) DEFAULT NULL,
  `relationtype` int(11) DEFAULT NULL,
  `description` text DEFAULT NULL,
  `CreateDatetime` datetime DEFAULT NULL,
  `LastUpdateDatetime` datetime DEFAULT NULL,
  `LastUpdate_UserID` int(11) DEFAULT NULL,
  PRIMARY KEY (`id`),
  KEY `fk_pxg_process_idx` (`processid`),
  KEY `fk_pxg_glossary_idx` (`glossaryid`),
  KEY `fk_pxg_reltype_idx` (`relationtype`),
  KEY `fk_pxg_user_idx` (`LastUpdate_UserID`),
  CONSTRAINT `fk_pxg_process` FOREIGN KEY (`processid`) REFERENCES `process` (`id`),
  CONSTRAINT `fk_pxg_glossary` FOREIGN KEY (`glossaryid`) REFERENCES `glossary` (`ID`),
  CONSTRAINT `fk_pxg_reltype` FOREIGN KEY (`relationtype`) REFERENCES `process_x_glossary_relationtype` (`id`),
  CONSTRAINT `fk_pxg_user` FOREIGN KEY (`LastUpdate_UserID`) REFERENCES `people` (`ID`)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COLLATE=utf8mb4_general_ci;

-- Relation type table
CREATE TABLE `process_x_glossary_relationtype` (
  `id` int(11) NOT NULL AUTO_INCREMENT,
  `PrimaryName` varchar(90) DEFAULT NULL,
  `Description` varchar(255) DEFAULT NULL,
  `Priority` int(11) DEFAULT NULL,
  `ReverseName` varchar(128) DEFAULT NULL,
  `CreateDatetime` datetime DEFAULT NULL,
  `LastUpdateDatetime` datetime DEFAULT NULL,
  `LastUpdate_UserID` int(11) DEFAULT NULL,
  PRIMARY KEY (`id`)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COLLATE=utf8mb4_general_ci;

-- Default relation type
INSERT INTO `process_x_glossary_relationtype` 
VALUES (1, 'Process is related to Glossary', 'The text that describes the relationship between these objects', NULL, NULL, NOW(), NOW(), 1);
```

1. تفعيل العلاقة في RelationshipManager.java (إزالة التعليق)
2. اختبار العلاقة بإضافة سجل تجريبي
