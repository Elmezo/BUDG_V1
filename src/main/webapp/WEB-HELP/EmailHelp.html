📧 Email Configuration Guide (SMTP)

for Automatic Notifications

⚙️ Why Do You Need to Configure Email Settings?

To enable the application to send automatic notifications and emails to other users, you need to add your Outgoing Mail Server (SMTP) information.

🔧 Required Information for Setup

To configure correctly, you'll need to provide the following information in the Email Settings section:

Information Description
Email Full email address (e.g., user@gmail.com)
Password Password (Note: For most services, you need an App Password, not your regular password)
SMTP Server Outgoing mail server name (e.g., smtp.gmail.com)
Port Port number (Most common: 587 or 465)
Encryption Encryption type (SSL or TLS/STARTTLS)

📋 Recommended Settings for Major Services (Updated 2025)

1. Gmail / Google Workspace

SMTP Server: smtp.gmail.com Port: 587 (Recommended with STARTTLS) or 465 (with SSL) Email: Your full email address Password: Must create an App Password Encryption: TLS (for Port 587) or SSL (for Port 465)
Important for Gmail:
  • If Two-Factor Authentication (2FA) is enabled: Create an App Password from Google Account Settings
  • Select "Mail" as the app type
  • You'll receive a 16-character password (use this instead of your regular password)

2. Outlook / Hotmail / Microsoft

SMTP Server: smtp-mail.outlook.com Port: 587 (with STARTTLS) Email: Your full email address Password: Regular password (or App Password if 2FA is enabled) Encryption: STARTTLS

3. Yahoo Mail

SMTP Server: smtp.mail.yahoo.com Port: 465 (with SSL) or 587 (with TLS) Email: Your full email address Password: Create App Password from Yahoo security settings Encryption: SSL (for Port 465) or TLS (for Port 587)

🔍 For Corporate Email or Other Services

If you're using email from:

  • Your company (e.g., name@company.com)
  • Hosting provider (Bluehost, GoDaddy, etc.)
  • Other services (iCloud, AOL, etc.)

You can:

  1. Search for: "SMTP settings for [your service provider name]"
  2. Check your email provider's documentation
  3. Contact your service provider's technical support

💡 Troubleshooting Tips

Initial Testing:

  1. Start with Port 587 with TLS/STARTTLS - This is the most secure and widely supported
  2. If it doesn't work, try Port 465 with SSL
  3. Make sure to use App Password if the service supports it

Common Errors and Solutions:

Issue Possible Solution
"Authentication failed" Verify you're using App Password, not your regular password
"Connection refused" Check if port and server settings are correct
"SSL/TLS required" Ensure the correct encryption option is enabled
Cannot send test email Check firewall or antivirus settings

Verification Steps:

  1. Confirm email address is correct
  2. Verify you're using the right password (App Password if required)
  3. Check port and encryption settings
  4. Use the "Test Connection" or "Send Test Email" button in the application

🚀 After Successful Configuration

  1. Send a test email to confirm settings are working
  2. Save your App Password in a secure place (you won't be able to see it again)
  3. Remember to update settings if you change your account password
