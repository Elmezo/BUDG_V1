القسم 7: ملاحظات مهمة للتطبيق
================================================================================

1. Naming Conventions:
   - Process/Project tables: lowercase (processid, datasetid)
   - Policy tables: PascalCase (Policy_ID, DatasetID)
   - يجب مراعاة الاختلاف عند كتابة SQL queries

2. Table Alias:
   - process: pr
   - project: prj
   - policy: po
   - dataset: d
   - attribute: a
   - system: s
   - glossary: g

3. ID Column Names:
   - process.id, project.id, system.id (lowercase)
   - dataset.ID, policy.ID, glossary.ID (uppercase)
   - يجب مراعاة الاختلاف في SQL queries

4. Foreign Key Constraints:
   - جميع الجداول لديها foreign key constraints
   - يجب التأكد من وجود السجلات قبل إنشاء العلاقات

5. Performance:
   - استخدام IN (SELECT ...) قد يكون بطيئاً للبيانات الكبيرة
   - يمكن تحسينه لاحقاً باستخدام JOIN إذا لزم الأمر
