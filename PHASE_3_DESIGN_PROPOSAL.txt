================================================================================
2. تطبيق القواعد (Rule Enforcement)
================================================================================

2.1 نظرة عامة
--------------
القواعد موجودة في جدول values_rule:
- MAX_LENGTH: الحد الأقصى لطول القيمة
- REQUIRED: إلزامية الحقل
- UNIQUE: فريدية القيمة

2.2 فلسفة Axon
---------------
- Governance-oriented validation (موجه للحوكمة)
- Rules تمنع الرفع فقط عند الانتهاك الواضح
- ليست صرامة مستودع البيانات

2.3 استراتيجية التطبيق
-----------------------

2.3.1 MAX_LENGTH
----------------
الوصف:
- يتحقق من أن طول القيمة لا يتجاوز القيمة المحددة في rule_value

التطبيق:
```java
private void validateMaxLength(Connection conn, int fieldId, String value, String ruleValue) 
    throws IllegalArgumentException {
    if (value != null && value.length() > Integer.parseInt(ruleValue)) {
        throw new IllegalArgumentException(
            "Value exceeds maximum length of " + ruleValue + " characters"
        );
    }
}
```

متى يتم التطبيق:
- قبل إدراج القيمة في values_entry
- فقط إذا كانت القيمة غير NULL

2.3.2 REQUIRED
--------------
الوصف:
- يتحقق من أن الحقل له قيمة (غير NULL وغير فارغ)

التطبيق:
```java
private void validateRequired(Connection conn, int fieldId, String value) 
    throws IllegalArgumentException {
    if (value == null || value.trim().isEmpty()) {
        throw new IllegalArgumentException(
            "Field is required but value is empty"
        );
    }
}
```

متى يتم التطبيق:
- قبل إدراج القيمة في values_entry
- لكل صف في الملف

2.3.3 UNIQUE
------------
الوصف:
- يتحقق من أن القيمة فريدة داخل نفس الرفع (entry_ref)
- Application-level فقط (لا database constraint)

التطبيق:
```java
private void validateUnique(Connection conn, int fieldId, String value, int entryRefId) 
    throws IllegalArgumentException {
    if (value == null || value.isEmpty()) {
        return; // NULL values are allowed (unless REQUIRED)
    }
    
    String checkSql = "SELECT COUNT(*) FROM values_entry " +
                      "WHERE field_id = ? AND value_text = ? AND entry_ref_id = ?";
    try (PreparedStatement ps = conn.prepareStatement(checkSql)) {
        ps.setInt(1, fieldId);
        ps.setString(2, value);
        ps.setInt(3, entryRefId);
        try (ResultSet rs = ps.executeQuery()) {
            if (rs.next() && rs.getInt(1) > 0) {
                throw new IllegalArgumentException(
                    "Value must be unique within this upload: " + value
                );
            }
        }
    }
}
```

النطاق:
- داخل نفس entry_ref فقط (نفس الرفع)
- لا يتحقق عبر الرفوعات المختلفة
- قابل للتوسيع لاحقاً (مثلاً: unique across all uploads)

2.4 مكان التطبيق في الكود
--------------------------
في method `processFileUpload()`:
- بعد التحقق من data type
- قبل إدراج القيمة في values_entry
- لكل قيمة قبل إضافتها للـ batch

الكود المقترح:
```java
// في حلقة إدراج القيم (بعد السطر 489)
if (val != null && !val.isEmpty()) {
    // ... reference resolution ...
    // ... soft data type validation ...
    
    // Rule enforcement (Phase 3)
    validateFieldRules(conn, fieldId, val, rowIndex, refId);
}

private void validateFieldRules(Connection conn, int fieldId, String value, 
                                int rowIndex, int entryRefId) throws SQLException {
    String rulesSql = "SELECT rule_type, rule_value FROM values_rule WHERE field_id = ?";
    try (PreparedStatement ps = conn.prepareStatement(rulesSql)) {
        ps.setInt(1, fieldId);
        try (ResultSet rs = ps.executeQuery()) {
            while (rs.next()) {
                String ruleType = rs.getString("rule_type");
                String ruleValue = rs.getString("rule_value");
                
                switch (ruleType) {
                    case "MAX_LENGTH":
                        validateMaxLength(conn, fieldId, value, ruleValue);
                        break;
                    case "REQUIRED":
                        validateRequired(conn, fieldId, value);
                        break;
                    case "UNIQUE":
                        validateUnique(conn, fieldId, value, entryRefId);
                        break;
                }
            }
        }
    }
}
```

2.5 معالجة الأخطاء
-------------------
- عند انتهاك أي قاعدة، يتم إيقاف الرفع
- يتم إرجاع رسالة خطأ واضحة تحتوي على:
  - اسم الحقل
  - نوع القاعدة المنتهكة
  - رقم الصف
  - القيمة المرفوضة

2.6 الأداء
----------
- يتم جلب القواعد مرة واحدة لكل field (caching محتمل)
- UNIQUE check يتطلب query إضافية (يمكن تحسينها لاحقاً)
- التأثير على الأداء محدود لأن القواعد تطبق فقط على القيم غير NULL

3.3.2 Detection
---------------
الكشف عن نوع الملف:

private boolean isExcelFile(String fileName) {
    String lower = fileName.toLowerCase();
    return lower.endsWith(".xlsx") || lower.endsWith(".xls");
}

3.3.3 Reading Excel
-------------------
Method جديد لقراءة Excel:
```java
private List<String[]> readExcelFile(Part filePart) throws Exception {
    List<String[]> rows = new ArrayList<>();
    
    try (InputStream is = filePart.getInputStream()) {
        Workbook workbook;
        if (filePart.getSubmittedFileName().toLowerCase().endsWith(".xlsx")) {
            workbook = new XSSFWorkbook(is);
        } else {
            workbook = new HSSFWorkbook(is);
        }
        
        Sheet sheet = workbook.getSheetAt(0); // First sheet
        Iterator<Row> rowIterator = sheet.iterator();
        
        while (rowIterator.hasNext()) {
            Row row = rowIterator.next();
            List<String> cellValues = new ArrayList<>();
            
            Iterator<Cell> cellIterator = row.cellIterator();
            while (cellIterator.hasNext()) {
                Cell cell = cellIterator.next();
                String value = getCellValueAsString(cell);
                cellValues.add(value);
            }
            
            if (!cellValues.isEmpty()) {
                rows.add(cellValues.toArray(new String[0]));
            }
        }
        
        workbook.close();
    }
    
    return rows;
}

private String getCellValueAsString(Cell cell) {
    if (cell == null) return "";
    
    switch (cell.getCellType()) {
        case STRING:
            return cell.getStringCellValue();
        case NUMERIC:
            if (DateUtil.isCellDateFormatted(cell)) {
                return cell.getDateCellValue().toString();
            } else {
                return String.valueOf(cell.getNumericCellValue());
            }
        case BOOLEAN:
            return String.valueOf(cell.getBooleanCellValue());
        case FORMULA:
            return cell.getCellFormula();
        default:
            return "";
    }
}
```

-------------------
- ملف Excel فارغ

3.5 الأداء

- يجب استخدام streaming إذا أمكن
