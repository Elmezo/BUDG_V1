Saved Search Multi-Facet Filtering Fix

التاريخ: ديسمبر 2025
الحالة: ✅ تم الإصلاح

================================================================================
📋 وصف المشكلة (Problem Description)
================================================================================

المشكلة المُبلغ عنها من المستخدم:
"لما باجي احفظ search واجي استدعية تاني من My searches بيجبلي ال search في ال 
facet اللي انا ببحث فيها مظبوط لكن مش بيعمل filteration لباقي ال facet"

الترجمة:
When the user saves a search and then loads it again from "My Searches", the 
search correctly filters the active facet, but does NOT filter the other facets.

مثال على المشكلة:
---------------
1. المستخدم يبحث في Process عن "Customer"
2. يضيف شرط AND في Dataset عن "Personal"
3. يحفظ البحث باسم "Customer Process with Personal Data"
4. ينفذ البحث - جميع الفاسيتات تتصفى بشكل صحيح ✓
5. يستدعي البحث المحفوظ من "My Searches"
6. النتيجة:
   - Process facet: تظهر نتائج مصفاة ✓
   - Dataset facet: تظهر جميع البيانات (غير مصفاة) ✗
   - Attribute facet: تظهر جميع البيانات (غير مصفاة) ✗
   - System facet: تظهر جميع البيانات (غير مصفاة) ✗

================================================================================
🔍 السبب الجذري (Root Cause)
================================================================================

الملف المتأثر: saved-searches.js
الدالة المتأثرة: executeSearchGroups()
السطر: ~553 (قبل الإصلاح)

الكود القديم:
```javascript
// Check if executeSearchWithConditions exists
if (typeof executeSearchWithConditions === 'function') {
    await executeSearchWithConditions(targetCategory, convertedConditions);
} else if (typeof executeMultiConditionSearch === 'function') {
    await executeMultiConditionSearch();
}
```

المشكلة:
--------
1. الكود يستخدم `executeSearchWithConditions()` أولاً
2. هذه الدالة تبحث فقط في فاسيت واحد (الفاسيت النشط)
3. لا تقوم بتحديث باقي الفاسيتات

الفرق بين الدالتين:
--------------------

executeSearchWithConditions(category, conditions):
  ✗ تبحث في فاسيت واحد فقط
  ✗ لا تستدعي Unison Search API
  ✗ لا تحدث updateAllFacets()
  ✗ لا تحدث counts/indicators في باقي الفاسيتات
  
executeMultiConditionSearch():
  ✓ تفحص إذا كان البحث متعدد الفاسيتات
  ✓ تستدعي Unison Search API للبحث عبر الفاسيتات
  ✓ تستدعي updateAllFacets() لتحديث جميع الفاسيتات
  ✓ تحدث counts/indicators في جميع الفاسيتات
  ✓ تحفظ النتائج في currentUnisonSearchResults

================================================================================
✅ الحل (Solution)
================================================================================

التعديل المطبق:
--------------
1. عكس ترتيب أولوية الدوال
2. استخدام executeMultiConditionSearch() أولاً
3. إضافة تعليقات توضيحية مفصلة
4. إضافة console logs للـ debugging
5. تحديث الفاسيت النشط قبل تنفيذ البحث

الكود الجديد:
```javascript
// Switch to the target category before executing search
console.log('[SAVED SEARCH] Switching to target category:', targetCategory);
const categoryItems = document.querySelectorAll('.category-item');
categoryItems.forEach(item => {
    if (item.getAttribute('data-category') === targetCategory) {
        item.classList.add('active', 'current');
    } else {
        item.classList.remove('active', 'current');
    }
});

// Show the query builder container
const builderContainer = document.getElementById('queryBuilderContainer');
if (builderContainer) {
    builderContainer.style.display = 'block';
}

// ALWAYS use executeMultiConditionSearch() for saved searches
console.log('[SAVED SEARCH] Executing search with', convertedConditions.length, 'conditions');

if (typeof executeMultiConditionSearch === 'function') {
    await executeMultiConditionSearch();
} else if (typeof executeSearchWithConditions === 'function') {
    // Fallback
    console.warn('[SAVED SEARCH] executeMultiConditionSearch not available');
    await executeSearchWithConditions(targetCategory, convertedConditions);
}
```

================================================================================
🔄 كيف يعمل الإصلاح (How the Fix Works)
================================================================================

تسلسل التنفيذ الجديد:
---------------------

1. استدعاء runSavedSearch(searchId)
   ↓
2. جلب بيانات البحث من الـ API
   ↓
3. تحويل searchGroups إلى convertedConditions
   ↓
4. تحديث searchConditions array
   ↓
5. تحديث الفاسيت النشط في الـ UI (جديد)
   ↓
6. استدعاء executeMultiConditionSearch() (تم التبديل)
   ↓
7. executeMultiConditionSearch يفحص الشروط:
   - إذا كان هناك شروط في أكثر من فاسيت → Unison Search
   - إذا كان هناك شرط FIND → Unison Search
   ↓
8. استدعاء executeUnisonSearch(searches, options)
   ↓
9. Backend يعالج البحث ويعيد نتائج لكل الفاسيتات
   ↓
10. استدعاء updateAllFacets(unisonResults, activeCategory)
    ↓
11. updateAllFacets يقوم بـ:
    - تحديث counts لجميع الفاسيتات (loop على كل facetId)
    - استدعاء updateFacetIndicator() لكل فاسيت
    - تحديث currentUnisonSearchResults
    - عرض البيانات للفاسيت النشط
    ↓
12. ✅ جميع الفاسيتات الآن مصفاة بشكل صحيح!
